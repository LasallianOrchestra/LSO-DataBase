---------------------------------------------------------------------
DEFECTS FOUND AND FIXED DURING VALIDATION
---------------------------------------------------------------------
1. Observer feedback loop. The empty-state row was rewritten on every apply,
   which re-triggered the table MutationObserver and detached the reset button
   while it was being clicked. Fixed by writing the empty state only when it is
   created or when its wording changes, and by having the observer react only to
   real account-row changes. Re-measured: 1 DOM mutation instead of 303, 0
   self-triggered applies.
2. Sort could mistake its own re-ordering for a new base order, so "Priority"
   no longer restored the action-first sequence after another sort. Fixed by
   capturing the base order from the row ELEMENTS (a real re-render always
   replaces the <tr> nodes, the console's sorting only moves them).
3. Touch targets below 44px on tablets (the search field's 36px clear button).
   Fixed in the V86 CSS layer; the audit's guard G7 measurement is clean.
4. The 44px clear button overlapped the field's right padding on phones; the
   input now reserves 62px for it below 980px.
5. The status label was pinned by the shared night layer's !important
   paragraph rule; the console no longer fights it (the shared night colour is
   kept, ~7.5:1 contrast on the night card).
