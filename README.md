# LSO Orchestra Management System — GitHub Ready V39

This folder contains only the active website/PWA files required for the current V39 deployment.

## Upload through GitHub.com

1. Extract the ZIP on your computer.
2. Open the `LSO-GitHub-Ready-V39` folder.
3. Upload the **contents inside the folder**, not the ZIP file itself.
4. In the repository settings, enable GitHub Pages from the branch and root folder that contain `index.html`.

The package intentionally excludes retired version files, validation notes, and private SQL setup scripts. Database changes must be run privately in the Supabase SQL Editor, not published through GitHub Pages.
