DATABASE
- No Supabase script is required. The console reads the account list through the
  RPCs the Accounts page already calls (public.lso_list_accounts ->
  public.lso_account_json) plus the shared member directory, and writes nothing.
- lastLoginAt is database-dependent: where the database does not track sign-ins
  the console hides the "Most recent sign-in" sort option instead of offering a
  dead choice. See the guide, section 2.

INSTALL ORDER
1. Upload the NEW file and every UPDATED file above.
2. No SQL to run.
3. Reload the site. The cache marker changed, so the previous lso-website-*
   cache is deleted automatically; the console then appears at
   Accounts → Account Management for the Administrator.
