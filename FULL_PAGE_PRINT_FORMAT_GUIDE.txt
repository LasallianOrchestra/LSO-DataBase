LSO FULL-PAGE PORTRAIT PRINT UPDATE - VERSION 31

CHANGES
- The official LSO template now fills the complete A4 portrait page in generated print layouts.
- Browser print CSS uses zero page margins and zero sheet margins.
- The printable Attendance heading "Risk Signals" is now labeled "Rate".
- Page-number badges have been removed from all HTML-generated prints.
- Page numbers have also been removed from the Monthly Report PDF generator.
- Content remains organized inside the template's safe body area so text does not cover the official header and footer.
- Database, authentication, permissions, Attendance data, Duty Hours data, and non-print screens were not changed.

DEPLOYMENT
1. Upload every file in this folder to the GitHub Pages publishing root.
2. Confirm that index.html, branding-print-fullbleed-v31.js, workflow-attendance-month-v5.js,
   monthly-report-print-v31.js, pwa-enterprise-v31.js, service-worker-enterprise-v31.js,
   and refresh-print-fullbleed-v31.html are present.
3. After GitHub Pages finishes deploying, open:
   https://nicpeanut31.github.io/LSO-DataBase/refresh-print-fullbleed-v31.html
4. Close and reopen an installed PWA before testing print generation.

IMPORTANT ABOUT PHYSICAL PRINTERS
The website requests A4 portrait with zero margins. For the template to physically reach every paper edge,
select "Margins: None" and enable "Background graphics" in the browser print dialog. The printer itself must
support borderless A4 printing; printers with a non-printable hardware edge may still leave a thin white border.
PDF downloads generated by the system retain the full A4 template canvas.
